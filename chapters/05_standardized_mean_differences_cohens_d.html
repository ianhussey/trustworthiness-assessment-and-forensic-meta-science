6.1 Means and standard deviations on bounded scales

Standardised effect sizes are built from means and standard deviations, so it helps to have a feel for which combinations of the two a given scale can produce. Most scales in psychology are bounded and produce integer responses: a 1–7 Likert item cannot produce a response of 0 or of 4.5. The app below lets you build a sample on such a scale. Set the logical minimum and maximum of the scale, and then set the number of observations at each response option in either of two ways. First, you can draw the distribution: click anywhere in a column to set its bar to that height, or hold the mouse button down and drag across the plot to draw the whole histogram in one movement. The vertical axis rescales when you release, so dragging a bar to the top of the plot makes room for larger counts. Second, you can type the exact number of observations for each response option into the boxes under the axis.

The mean and the standard deviation are plotted below the frequencies, each with its 95% confidence interval, and update as you go. An interval for a standard deviation is rarely reported, but it can be calculated, from the chi-squared distribution. Both intervals assume normally distributed data, so they do not respect the bounds of the scale.

6.2 Standardisation

The same construct is often measured with different scales, and different scales have different units. Depression, for example, is commonly measured with the BDI-II, which ranges from 0 to 63, the PHQ-9, which ranges from 0 to 27, and the HAM-D, which ranges from 0 to 52. A difference of 5 points between two groups means something different on each of them, so results from studies that used different scales cannot be compared or combined in their original units.

The plot below shows these three scales, each with its logical range and the mean ± 1 SD of a hypothetical sample of depressed patients. The values are illustrative, not taken from a particular study. The buttons re-express the same three samples in different units:

  • Scale units are the original units of each scale.
  • SD units divide every score by that sample’s standard deviation. This is the standardisation used by Cohen’s d and other standardised mean differences.
  • POMP (percent of maximum possible) re-expresses every score as a percentage of the distance from the scale’s minimum to its maximum.

Switch between them and pay attention to what lines up and what does not.

Standardising by the SD makes one thing comparable across scales: the unit. One SD is the same length on every scale, which is what allows a mean difference of 5 points on the BDI-II to be compared with a mean difference of 2.5 points on the PHQ-9. It does not make anything else comparable. The three samples still have different means in SD units, and the scales still have different ranges. Note also that the unit is a property of the sample, not of the scale: a study that recruited a more homogeneous sample would have a smaller SD, and the same difference in scale points would become a larger standardised difference (see Section 6.2.1).

The second plot shows why this matters for effect sizes. It adds a second group to each scale: a control condition and an intervention condition from a hypothetical trial of a treatment for depression, again with illustrative values, and with the same SD in both conditions. The panel underneath shows the difference between the two means on each scale, in whichever units are selected. Lower scores mean less severe depression, so a negative difference favours the intervention.

In scale points, the three trials appear to have found very different effects: 6 points, 2.5 points, and 3.3 points. In SD units, they are d = −0.60, −0.50, and −0.55, which is what we might expect from three trials of the same treatment. Standardising has not made the three results identical, and it should not: it has only put them in the same units so that they can be compared.

POMP makes a different thing comparable: the range. Every scale runs from 0 to 100, but the samples’ means and SDs still differ. POMP units depend only on the scale, not on the sample, but they assume that the full range of one scale corresponds to the full range of another, which need not be true.

6.2.1 Range restriction

Standardisation solves one problem and creates another. Because Cohen’s d divides the mean difference by the SD of the sample, anything that changes the SD changes d, even when the effect of the intervention in scale points is exactly the same. The SD of a sample depends on who was recruited. A trial that accepts anyone with a diagnosis of depression will include a wide range of severity. A trial with narrow inclusion criteria, for example one that only accepts patients whose baseline scores fall within a particular band, will include a much narrower range. This is called range restriction, and it shrinks the SD.

The plot below shows two hypothetical trials that used the same scale, the BDI-II, and found exactly the same difference between the intervention and control conditions: 5 points. Study A recruited a sample with a wide range of severity, and Study B recruited a sample with a restricted range. Use the slider to change how restricted Study B’s sample is.

The intervention did exactly the same thing in both studies: it lowered scores by 5 points. In the default setting, Study B’s d is nevertheless twice the size of Study A’s, and a reader comparing the two standardised effect sizes would conclude that the intervention worked twice as well in Study B. The difference between the two values of d comes entirely from who was recruited.

This has several implications for trustworthiness assessment:

  • A standardised effect size cannot be interpreted without knowing the SD it was standardised by. When an effect size seems implausibly large, check whether the SDs are unusually small for that scale, compared with other studies of similar populations.
  • Standardised effect sizes from studies with different inclusion criteria are not directly comparable, even when the studies used the same scale. When the studies did use the same scale, the mean difference in scale points is often the more informative comparison.
  • Range restriction is only one of the things that change the SD. Others include the reliability of the measure, floor and ceiling effects, and which SD was used as the standardiser (for example, the baseline SD, the pooled SD at post-treatment, or the SD of change scores).

6.3 Cohen’s d from two samples

Cohen’s d for two independent groups is the difference between their means divided by their pooled standard deviation:

\[ d = \frac{M_1 - M_2}{SD_{pooled}}, \qquad SD_{pooled} = \sqrt{\frac{(n_1 - 1)SD_1^2 + (n_2 - 1)SD_2^2}{n_1 + n_2 - 2}} \]

The app below works in the same way as the one above, but with two samples on the same scale: an intervention condition and a control condition. Draw or type the frequencies for each condition, and the estimates below them update as you go, each with its 95% confidence interval. They are plotted in three groups, each with its own axis: the two means and the difference between them (intervention minus control), the two SDs and the pooled SD, and the standardised mean difference, Cohen’s d. The first two groups are in the units of the scale, whereas d is in standard deviations. The interval for the mean difference uses the t distribution, the interval for the pooled SD uses the chi-squared distribution, and the interval for d uses the noncentral t distribution, as in the worked example in Section 8.1. Try changing only the spread of the two samples while keeping their means the same, to see how much d depends on the standard deviation, and try to find the largest d that the scale allows.

// the plot below attaches the button's action
dButtons = html`<div class="sb-buttons">
  <button class="btn btn-quarto sb-clear">Clear</button>
</div>`
viewof dMin = Inputs.number({value: 1, step: 1, label: "Scale minimum"})
viewof dMax = Inputs.number({value: 7, step: 1, label: "Scale maximum"})
dPlot = {
  const scores = scaleScores(dMin, dMax)
  if (!scores) return scaleMessage()
  const groups = [
    {label: "Intervention condition", short: "Intervention", store: dStores.intervention, colour: "#2780e3"},
    {label: "Control condition", short: "Control", store: dStores.control, colour: "#d9622b"}
  ]
  // both panels share a vertical axis, so that the heights of their bars are comparable
  const tallest = () => d3.max(groups, g => d3.max(scores, s => g.store.get(s) ?? 0))
  const estimatesPlot = html`<div></div>`
  const grey = "#8a8a8a"
  // the estimates are plotted in three subplots, by type, so that each type has its own horizontal axis
  const subplots = [
   {title: "Standardized Mean Difference", names: ["Cohen's d"], unit: "Standardized units", include: [-1, 1]},
    {title: "Means", names: [...groups.map(g => `${g.short} mean`), "Mean difference"], unit: "Scale units", include: [0, 1]},
    {title: "Standard deviations", names: [...groups.map(g => `${g.short} SD`), "Pooled SD"], unit: "Scale units", include: [0, 1]}
  ]
  const update = () => {
    // rows of the estimates subplots: each condition's mean and SD, then the three effect size statistics
    const rows = []
    for (const g of groups) {
      const stats = g.panel.stats()
      g.title.textContent = `${g.label} (n = ${stats.n})`
      const [lower, upper] = meanCi(stats) ?? [stats.mean, stats.mean]
      if (stats.n > 0) rows.push({name: `${g.short} mean`, est: stats.mean, lower, upper, colour: g.colour})
      const [sdLower, sdUpper] = sdCi(stats) ?? [stats.sd, stats.sd]
      if (stats.n > 1) rows.push({name: `${g.short} SD`, est: stats.sd, lower: sdLower, upper: sdUpper, colour: g.colour})
    }
    const a = groups[0].panel.stats(), b = groups[1].panel.stats()
    const df = a.n + b.n - 2
    const pooled = Math.sqrt((a.ss + b.ss) / df)
    if (a.n > 0 && b.n > 0 && df > 0 && pooled > 0) {
      const diff = a.mean - b.mean
      const scale = Math.sqrt(1 / a.n + 1 / b.n)
      const tCrit = tQuantile(0.975, df)
      // Cohen's d: the bounds are the noncentrality parameters under which the observed t would sit at the
      // 97.5th and 2.5th percentiles of the noncentral t distribution, converted from t to d
      const t = diff / (pooled * scale)
      const ncp = p => bisect(x => 1 - nctCdf(t, df, x), p, -10 - 2 * Math.abs(t), 10 + 2 * Math.abs(t))
      rows.push(
        // mean difference: t distribution
        {name: "Mean difference", est: diff, lower: diff - tCrit * pooled * scale, upper: diff + tCrit * pooled * scale, colour: grey},
        // pooled SD: chi-squared distribution
        {name: "Pooled SD", est: pooled, lower: pooled * Math.sqrt(df / chisqQuantile(0.975, df)), upper: pooled * Math.sqrt(df / chisqQuantile(0.025, df)), colour: grey},
        {name: "Cohen's d", est: diff / pooled, lower: ncp(0.025) * scale, upper: ncp(0.975) * scale, colour: grey}
      )
    }
    estimatesPlot.replaceChildren(...estimateSubplots(subplots, rows, width))
  }
  for (const g of groups) {
    g.title = html`<div class="sb-title" style="color: ${g.colour};"></div>`
    g.panel = frequencyPanel(scores, g.store, {tallest, onChange: ({rescaled}) => {
      if (rescaled) groups.forEach(other => { if (other !== g) other.panel.refresh() })
      update()
    }})
    g.panel.style.setProperty("--sb", g.colour)
  }
  dButtons.querySelector(".sb-clear").onclick = () => {
    groups.forEach(g => g.store.clear())
    groups.forEach(g => g.panel.refresh())
    update()
  }
  update()
  return html`<div>
    ${groups.map(g => html`<div>${g.title}${g.panel}</div>`)}
    <div class="sb-title">Estimates with 95% CIs</div>
    ${estimatesPlot}
  </div>`
}

dStores = ({

function frequencyPanel(scores, store, {onChange = () => {}, tallest} = {}) {
  // a histogram of the counts in store (a Map of score -> count) that can be edited by drawing in the plot or by
  // typing counts under the axis. onChange is called after every edit, with rescaled: true if the vertical axis
  // may have changed. tallest optionally supplies the count that the vertical axis has to fit, for panels that
  // share an axis. the returned element has two extra methods: stats(), and refresh() to redraw after the store
  // has been changed from outside
  const count = s => store.get(s) ?? 0
  const clamp = (x, min, max) => Math.max(min, Math.min(max, x))

  // the plot is built once and then updated in place, so that it is not replaced in the middle of a drag
  const bars = scores.map(() => html`<div class="sb-bar"></div>`)
  const ghosts = scores.map(() => html`<div class="sb-ghost"><span></span></div>`)
  const grid = html`<div></div>`
  const plot = html`<div class="sb-plot">${grid}${scores.map((s, i) => html`<div class="sb-barcol">${ghosts[i]}${bars[i]}</div>`)}</div>`
  const inputs = scores.map(s => html`<input type="number" min="0" step="1" title="Number of observations at ${s}" aria-label="Number of observations at ${s}">`)
  const node = html`<div class="sample-builder">
    ${plot}
    <div class="sb-axis">${scores.map(s => html`<span>${s}</span>`)}</div>
    <div class="sb-counts">${inputs}</div>
  </div>`
  node.stats = () => sampleStats(new Map(scores.map(s => [s, count(s)])))

  // top of the vertical axis: a round number with some headroom above the tallest bar
  let yMax
  const rescale = () => {
    yMax = Math.max(10, d3.nice(0, (tallest ? tallest() : d3.max(scores, count)) * 1.25, 5)[1])
    grid.replaceChildren(...d3.ticks(0, yMax, 5).filter(d => d > 0).map(d => html`<div class="sb-gridline" style="bottom: ${d / yMax * 100}%;"><span>${d}</span></div>`))
  }
  const paint = () => {
    scores.forEach((s, i) => {
      bars[i].style.height = `${Math.min(1, count(s) / yMax) * 100}%`
      // leave the box the user is typing in alone
      if (inputs[i] !== document.activeElement) inputs[i].value = count(s)
    })
  }
  node.refresh = () => { rescale(); paint() }

  // drawing: the pointer's column gives the response option and its height gives the count
  const at = e => {
    const r = plot.getBoundingClientRect()
    return {
      i: clamp(Math.floor((e.clientX - r.left) / r.width * scores.length), 0, scores.length - 1),
      k: clamp(Math.round((r.bottom - e.clientY) / r.height * yMax), 0, yMax)
    }
  }
  const showGhost = (cur) => ghosts.forEach((g, i) => {
    g.style.display = cur && i === cur.i ? "block" : "none"
    if (cur && i === cur.i) { g.style.height = `${cur.k / yMax * 100}%`; g.firstChild.textContent = cur.k }
  })
  let last = null
  plot.onpointerdown = e => {
    if (e.button !== 0) return
    e.preventDefault()
    plot.setPointerCapture(e.pointerId)
    last = at(e)
    store.set(scores[last.i], last.k)
    showGhost(last)
    paint()
    onChange({rescaled: false})
  }
  plot.onpointermove = e => {
    const cur = at(e)
    showGhost(cur)
    if (!last) return
    // also set any columns that the pointer skipped over since the last event, interpolating their heights
    const step = Math.sign(cur.i - last.i)
    for (let i = last.i; i !== cur.i; i += step) {
      store.set(scores[i + step], Math.round(last.k + (cur.k - last.k) * (i + step - last.i) / (cur.i - last.i)))
    }
    store.set(scores[cur.i], cur.k)
    last = cur
    paint()
    onChange({rescaled: false})
  }
  plot.onpointerup = plot.onpointercancel = () => {
    if (!last) return
    last = null
    showGhost(null)
    node.refresh()
    onChange({rescaled: true})
  }
  plot.onpointerleave = () => { if (!last) showGhost(null) }

  // typing: exact counts
  inputs.forEach((input, i) => {
    input.oninput = () => {
      store.set(scores[i], clamp(Math.floor(+input.value) || 0, 0, 9999))
      node.refresh()
      onChange({rescaled: true})
    }
    input.onblur = paint
  })

  node.refresh()
  return node
}

function meanCi({n, mean, sd}) {
  // 95% CI for a mean, or null if it cannot be calculated
  if (!(n > 1 && sd > 0)) return null
  const margin = tQuantile(0.975, n - 1) * sd / Math.sqrt(n)
  return [mean - margin, mean + margin]
}
function sdCi({n, sd}) {
  // 95% CI for an SD, or null if it cannot be calculated
  if (!(n > 1 && sd > 0)) return null
  return [sd * Math.sqrt((n - 1) / chisqQuantile(0.975, n - 1)), sd * Math.sqrt((n - 1) / chisqQuantile(0.025, n - 1))]
}

function sampleStats(counts) {
  // counts: Map of score -> number of observations. ss is the sum of squared deviations from the mean,
  // and sd is the sample SD (n - 1 denominator)
  const entries = [...counts]
  const n = d3.sum(entries, ([, k]) => k)
  const mean = d3.sum(entries, ([s, k]) => s * k) / n
  const ss = n > 0 ? d3.sum(entries, ([s, k]) => k * (s - mean) ** 2) : 0
  return {n, mean, ss, sd: Math.sqrt(ss / (n - 1))}
}

// quantiles of the t and chi-squared distributions, found by bisection on their cumulative distribution functions
function tQuantile(p, df) {
  const cdf = x => x > 0 ? 1 - 0.5 * betaI(df / (df + x * x), df / 2, 0.5) : 0.5 * betaI(df / (df + x * x), df / 2, 0.5)
  return bisect(cdf, p, -1e4, 1e4)
}
function chisqQuantile(p, df) {
  return bisect(x => gammaP(df / 2, x / 2), p, 0, df + 20 * Math.sqrt(2 * df) + 50)
}
function bisect(cdf, p, lower, upper) {
  for (let i = 0; i < 100; i++) {
    const mid = (lower + upper) / 2
    if (cdf(mid) < p) lower = mid; else upper = mid
  }
  return (lower + upper) / 2
}
function nctCdf(t, df, ncp) {
  // cumulative distribution function of the noncentral t distribution. T = (Z + ncp) / (U / sqrt(df)), where Z is
  // standard normal and U follows a chi distribution, so P(T <= t) is the average of normCdf(t * u / sqrt(df) - ncp)
  // over the distribution of U. the average is calculated by numerical integration (Simpson's rule)
  const logConstant = -(df / 2 - 1) * Math.LN2 - logGamma(df / 2)
  const density = u => u > 0 ? Math.exp((df - 1) * Math.log(u) - u * u / 2 + logConstant) : (df === 1 ? Math.exp(logConstant) : 0)
  const from = Math.max(0, Math.sqrt(df) - 8), to = Math.sqrt(df) + 8, steps = 400, h = (to - from) / steps
  let sum = 0
  for (let i = 0; i <= steps; i++) {
    const u = from + i * h
    sum += (i === 0 || i === steps ? 1 : i % 2 ? 4 : 2) * density(u) * normCdf(t * u / Math.sqrt(df) - ncp)
  }
  return sum * h / 3
}
function normCdf(x) {
  // Abramowitz & Stegun 7.1.26
  const t = 1 / (1 + 0.3275911 * Math.abs(x) / Math.SQRT2)
  const erf = 1 - (((((1.061405429 * t - 1.453152027) * t) + 1.421413741) * t - 0.284496736) * t + 0.254829592) * t * Math.exp(-x * x / 2)
  return x >= 0 ? 0.5 * (1 + erf) : 0.5 * (1 - erf)
}
function logGamma(x) {
  // Lanczos approximation
  const c = [76.18009172947146, -86.50532032941677, 24.01409824083091, -1.231739572450155, 0.001208650973866179, -0.000005395239384953]
  let y = x, sum = 1.000000000190015
  for (const cj of c) sum += cj / ++y
  return -(x + 5.5) + (x + 0.5) * Math.log(x + 5.5) + Math.log(2.5066282746310005 * sum / x)
}
function gammaP(a, x) {
  // regularised lower incomplete gamma function: series for small x, continued fraction otherwise
  if (x <= 0) return 0
  const front = Math.exp(-x + a * Math.log(x) - logGamma(a))
  if (x < a + 1) {
    let term = 1 / a, sum = term
    for (let n = 1; n < 500; n++) { term *= x / (a + n); sum += term; if (Math.abs(term) < Math.abs(sum) * 1e-14) break }
    return sum * front
  }
  let b = x + 1 - a, c = 1e300, d = 1 / b, h = d
  for (let i = 1; i < 500; i++) {
    const an = -i * (i - a)
    b += 2
    d = an * d + b; if (Math.abs(d) < 1e-300) d = 1e-300
    c = b + an / c; if (Math.abs(c) < 1e-300) c = 1e-300
    d = 1 / d
    const del = d * c
    h *= del
    if (Math.abs(del - 1) < 1e-14) break
  }
  return 1 - front * h
}
function betaI(x, a, b) {
  // regularised incomplete beta function, by continued fraction
  if (x <= 0) return 0
  if (x >= 1) return 1
  const front = Math.exp(logGamma(a + b) - logGamma(a) - logGamma(b) + a * Math.log(x) + b * Math.log(1 - x))
  const cf = (x, a, b) => {
    let c = 1, d = 1 - (a + b) * x / (a + 1)
    if (Math.abs(d) < 1e-300) d = 1e-300
    d = 1 / d
    let h = d
    for (let m = 1; m < 500; m++) {
      let aa = m * (b - m) * x / ((a + 2 * m - 1) * (a + 2 * m))
      d = 1 + aa * d; if (Math.abs(d) < 1e-300) d = 1e-300
      c = 1 + aa / c; if (Math.abs(c) < 1e-300) c = 1e-300
      d = 1 / d
      h *= d * c
      aa = -(a + m) * (a + b + m) * x / ((a + 2 * m) * (a + 2 * m + 1))
      d = 1 + aa * d; if (Math.abs(d) < 1e-300) d = 1e-300
      c = 1 + aa / c; if (Math.abs(c) < 1e-300) c = 1e-300
      d = 1 / d
      const del = d * c
      h *= del
      if (Math.abs(del - 1) < 1e-14) break
    }
    return h
  }
  return x < (a + 1) / (a + b + 2) ? front * cf(x, a, b) / a : 1 - front * cf(1 - x, b, a) / b
}

## Means and standard deviations on bounded scales {#sec-mean-sd-builder}

Standardised effect sizes are built from means and standard deviations, so it helps to have a feel for which combinations of the two a given scale can produce. Most scales in psychology are bounded and produce integer responses: a 1–7 Likert item cannot produce a response of 0 or of 4.5. The app below lets you build a sample on such a scale. ## Standardisation {#sec-standardisation}

The same construct is often measured with different scales, and different scales have different units. Depression, for example, is commonly measured with the BDI-II, which ranges from 0 to 63, the PHQ-9, which ranges from 0 to 27, and the HAM-D, which ranges from 0 to 52. A difference of 5 points between two groups means something different on each of them, so results from studies that used different scales cannot be compared or combined in their original units.

The plot below shows these three scales, each with its logical range and the mean ± 1 *SD* of a hypothetical sample of depressed patients. The values are illustrative, not taken from a particular study. The buttons re-express the same three samples in different units:

- **Scale units** are the original units of each scale.
- **SD units** divide every score by that sample's standard deviation. This is the standardisation used by Cohen's *d* and other standardised mean differences.
- **POMP** (percent of maximum possible) re-expresses every score as a percentage of the distance from the scale's minimum to its maximum.

Switch between them and pay attention to what lines up and what does not.

One *SD* is the same length on every scale, which is what allows a mean difference of 5 points on the BDI-II to be compared with a mean difference of 2.5 points on the PHQ-9. It does not make anything else comparable. The three samples still have different means in *SD* units, and the scales still have different ranges. Note also that the unit is a property of the sample, not of the scale: a study that recruited a more homogeneous sample would have a smaller *SD*, and the same difference in scale points would become a larger standardised difference (see @sec-range-restriction).

The panel underneath shows the difference between the two means on each scale, in whichever units are selected. Lower scores mean less severe depression, so a negative difference favours the intervention.

### Range restriction {#sec-range-restriction}

Standardisation solves one problem and creates another. Because Cohen's *d* divides the mean difference by the *SD* of the sample, anything that changes the *SD* changes *d*, even when the effect of the intervention in scale points is exactly the same. The *SD* of a sample depends on who was recruited. A trial that accepts anyone with a diagnosis of depression will include a wide range of severity. A trial with narrow inclusion criteria, for example one that only accepts patients whose baseline scores fall within a particular band, will include a much narrower range. This is called range restriction, and it shrinks the *SD*.

This has several implications for trustworthiness assessment:

- A standardised effect size cannot be interpreted without knowing the *SD* it was standardised by. When an effect size seems implausibly large, check whether the *SD*s are unusually small for that scale, compared with other studies of similar populations.
- Standardised effect sizes from studies with different inclusion criteria are not directly comparable, even when the studies used the same scale. When the studies did use the same scale, the mean difference in scale points is often the more informative comparison.
- Range restriction is only one of the things that change the *SD*. Others include the reliability of the measure, floor and ceiling effects, and which *SD* was used as the standardiser (for example, the baseline *SD*, the pooled *SD* at post-treatment, or the *SD* of change scores).

## Cohen's *d* from two samples {#sec-cohens-d-builder}

Cohen's *d* for two independent groups is the difference between their means divided by their pooled standard deviation:

$$
d = \frac{M_1 - M_2}{SD_{pooled}}, \qquad SD_{pooled} = \sqrt{\frac{(n_1 - 1)SD_1^2 + (n_2 - 1)SD_2^2}{n_1 + n_2 - 2}}
$$

The app below works in the same way as the one above, but with two samples on the same scale: an intervention condition and a control condition. Draw or type the frequencies for each condition, and the estimates below them update as you go, each with its 95% confidence interval. They are plotted in three groups, each with its own axis: the two means and the difference between them (intervention minus control), the two *SD*s and the pooled *SD*, and the standardised mean difference, Cohen's *d*. The first two groups are in the units of the scale, whereas *d* is in standard deviations. The interval for the mean difference uses the *t* distribution, the interval for the pooled *SD* uses the chi-squared distribution, and the interval for *d* uses the noncentral *t* distribution, as in the worked example in @sec-absence-of-evidence. Try changing only the spread of the two samples while keeping their means the same, to see how much *d* depends on the standard deviation, and try to find the largest *d* that the scale allows.

// shared by the apps above
function frequencyPanel(scores, store, {onChange = () => {}, tallest} = {}) {
  // a histogram of the counts in store (a Map of score -> count) that can be edited by drawing in the plot or by
  // typing counts under the axis. onChange is called after every edit, with rescaled: true if the vertical axis
  // may have changed. tallest optionally supplies the count that the vertical axis has to fit, for panels that
  // share an axis. the returned element has two extra methods: stats(), and refresh() to redraw after the store
  // has been changed from outside
  const count = s => store.get(s) ?? 0
  const clamp = (x, min, max) => Math.max(min, Math.min(max, x))

  // the plot is built once and then updated in place, so that it is not replaced in the middle of a drag
  const bars = scores.map(() => html`<div class="sb-bar"></div>`)
  const ghosts = scores.map(() => html`<div class="sb-ghost"><span></span></div>`)
  const grid = html`<div></div>`
  const plot = html`<div class="sb-plot">${grid}${scores.map((s, i) => html`<div class="sb-barcol">${ghosts[i]}${bars[i]}</div>`)}</div>`
  const inputs = scores.map(s => html`<input type="number" min="0" step="1" title="Number of observations at ${s}" aria-label="Number of observations at ${s}">`)
  const node = html`<div class="sample-builder">
    ${plot}
    <div class="sb-axis">${scores.map(s => html`<span>${s}</span>`)}</div>
    <div class="sb-counts">${inputs}</div>
  </div>`
  node.stats = () => sampleStats(new Map(scores.map(s => [s, count(s)])))

  // top of the vertical axis: a round number with some headroom above the tallest bar
  let yMax
  const rescale = () => {
    yMax = Math.max(10, d3.nice(0, (tallest ? tallest() : d3.max(scores, count)) * 1.25, 5)[1])
    grid.replaceChildren(...d3.ticks(0, yMax, 5).filter(d => d > 0).map(d => html`<div class="sb-gridline" style="bottom: ${d / yMax * 100}%;"><span>${d}</span></div>`))
  }
  const paint = () => {
    scores.forEach((s, i) => {
      bars[i].style.height = `${Math.min(1, count(s) / yMax) * 100}%`
      // leave the box the user is typing in alone
      if (inputs[i] !== document.activeElement) inputs[i].value = count(s)
    })
  }
  node.refresh = () => { rescale(); paint() }

  // drawing: the pointer's column gives the response option and its height gives the count
  const at = e => {
    const r = plot.getBoundingClientRect()
    return {
      i: clamp(Math.floor((e.clientX - r.left) / r.width * scores.length), 0, scores.length - 1),
      k: clamp(Math.round((r.bottom - e.clientY) / r.height * yMax), 0, yMax)
    }
  }
  const showGhost = (cur) => ghosts.forEach((g, i) => {
    g.style.display = cur && i === cur.i ? "block" : "none"
    if (cur && i === cur.i) { g.style.height = `${cur.k / yMax * 100}%`; g.firstChild.textContent = cur.k }
  })
  let last = null
  plot.onpointerdown = e => {
    if (e.button !== 0) return
    e.preventDefault()
    plot.setPointerCapture(e.pointerId)
    last = at(e)
    store.set(scores[last.i], last.k)
    showGhost(last)
    paint()
    onChange({rescaled: false})
  }
  plot.onpointermove = e => {
    const cur = at(e)
    showGhost(cur)
    if (!last) return
    // also set any columns that the pointer skipped over since the last event, interpolating their heights
    const step = Math.sign(cur.i - last.i)
    for (let i = last.i; i !== cur.i; i += step) {
      store.set(scores[i + step], Math.round(last.k + (cur.k - last.k) * (i + step - last.i) / (cur.i - last.i)))
    }
    store.set(scores[cur.i], cur.k)
    last = cur
    paint()
    onChange({rescaled: false})
  }
  plot.onpointerup = plot.onpointercancel = () => {
    if (!last) return
    last = null
    showGhost(null)
    node.refresh()
    onChange({rescaled: true})
  }
  plot.onpointerleave = () => { if (!last) showGhost(null) }

  // typing: exact counts
  inputs.forEach((input, i) => {
    input.oninput = () => {
      store.set(scores[i], clamp(Math.floor(+input.value) || 0, 0, 9999))
      node.refresh()
      onChange({rescaled: true})
    }
    input.onblur = paint
  })

  node.refresh()
  return node
}

function meanCi({n, mean, sd}) {
  // 95% CI for a mean, or null if it cannot be calculated
  if (!(n > 1 && sd > 0)) return null
  const margin = tQuantile(0.975, n - 1) * sd / Math.sqrt(n)
  return [mean - margin, mean + margin]
}
function sdCi({n, sd}) {
  // 95% CI for an SD, or null if it cannot be calculated
  if (!(n > 1 && sd > 0)) return null
  return [sd * Math.sqrt((n - 1) / chisqQuantile(0.975, n - 1)), sd * Math.sqrt((n - 1) / chisqQuantile(0.025, n - 1))]
}

function sampleStats(counts) {
  // counts: Map of score -> number of observations. ss is the sum of squared deviations from the mean,
  // and sd is the sample SD (n - 1 denominator)
  const entries = [...counts]
  const n = d3.sum(entries, ([, k]) => k)
  const mean = d3.sum(entries, ([s, k]) => s * k) / n
  const ss = n > 0 ? d3.sum(entries, ([s, k]) => k * (s - mean) ** 2) : 0
  return {n, mean, ss, sd: Math.sqrt(ss / (n - 1))}
}

// quantiles of the t and chi-squared distributions, found by bisection on their cumulative distribution functions
function tQuantile(p, df) {
  const cdf = x => x > 0 ? 1 - 0.5 * betaI(df / (df + x * x), df / 2, 0.5) : 0.5 * betaI(df / (df + x * x), df / 2, 0.5)
  return bisect(cdf, p, -1e4, 1e4)
}
function chisqQuantile(p, df) {
  return bisect(x => gammaP(df / 2, x / 2), p, 0, df + 20 * Math.sqrt(2 * df) + 50)
}
function bisect(cdf, p, lower, upper) {
  for (let i = 0; i < 100; i++) {
    const mid = (lower + upper) / 2
    if (cdf(mid) < p) lower = mid; else upper = mid
  }
  return (lower + upper) / 2
}
function nctCdf(t, df, ncp) {
  // cumulative distribution function of the noncentral t distribution. T = (Z + ncp) / (U / sqrt(df)), where Z is
  // standard normal and U follows a chi distribution, so P(T <= t) is the average of normCdf(t * u / sqrt(df) - ncp)
  // over the distribution of U. the average is calculated by numerical integration (Simpson's rule)
  const logConstant = -(df / 2 - 1) * Math.LN2 - logGamma(df / 2)
  const density = u => u > 0 ? Math.exp((df - 1) * Math.log(u) - u * u / 2 + logConstant) : (df === 1 ? Math.exp(logConstant) : 0)
  const from = Math.max(0, Math.sqrt(df) - 8), to = Math.sqrt(df) + 8, steps = 400, h = (to - from) / steps
  let sum = 0
  for (let i = 0; i <= steps; i++) {
    const u = from + i * h
    sum += (i === 0 || i === steps ? 1 : i % 2 ? 4 : 2) * density(u) * normCdf(t * u / Math.sqrt(df) - ncp)
  }
  return sum * h / 3
}
function normCdf(x) {
  // Abramowitz & Stegun 7.1.26
  const t = 1 / (1 + 0.3275911 * Math.abs(x) / Math.SQRT2)
  const erf = 1 - (((((1.061405429 * t - 1.453152027) * t) + 1.421413741) * t - 0.284496736) * t + 0.254829592) * t * Math.exp(-x * x / 2)
  return x >= 0 ? 0.5 * (1 + erf) : 0.5 * (1 - erf)
}
function logGamma(x) {
  // Lanczos approximation
  const c = [76.18009172947146, -86.50532032941677, 24.01409824083091, -1.231739572450155, 0.001208650973866179, -0.000005395239384953]
  let y = x, sum = 1.000000000190015
  for (const cj of c) sum += cj / ++y
  return -(x + 5.5) + (x + 0.5) * Math.log(x + 5.5) + Math.log(2.5066282746310005 * sum / x)
}
function gammaP(a, x) {
  // regularised lower incomplete gamma function: series for small x, continued fraction otherwise
  if (x <= 0) return 0
  const front = Math.exp(-x + a * Math.log(x) - logGamma(a))
  if (x < a + 1) {
    let term = 1 / a, sum = term
    for (let n = 1; n < 500; n++) { term *= x / (a + n); sum += term; if (Math.abs(term) < Math.abs(sum) * 1e-14) break }
    return sum * front
  }
  let b = x + 1 - a, c = 1e300, d = 1 / b, h = d
  for (let i = 1; i < 500; i++) {
    const an = -i * (i - a)
    b += 2
    d = an * d + b; if (Math.abs(d) < 1e-300) d = 1e-300
    c = b + an / c; if (Math.abs(c) < 1e-300) c = 1e-300
    d = 1 / d
    const del = d * c
    h *= del
    if (Math.abs(del - 1) < 1e-14) break
  }
  return 1 - front * h
}
function betaI(x, a, b) {
  // regularised incomplete beta function, by continued fraction
  if (x <= 0) return 0
  if (x >= 1) return 1
  const front = Math.exp(logGamma(a + b) - logGamma(a) - logGamma(b) + a * Math.log(x) + b * Math.log(1 - x))
  const cf = (x, a, b) => {
    let c = 1, d = 1 - (a + b) * x / (a + 1)
    if (Math.abs(d) < 1e-300) d = 1e-300
    d = 1 / d
    let h = d
    for (let m = 1; m < 500; m++) {
      let aa = m * (b - m) * x / ((a + 2 * m - 1) * (a + 2 * m))
      d = 1 + aa * d; if (Math.abs(d) < 1e-300) d = 1e-300
      c = 1 + aa / c; if (Math.abs(c) < 1e-300) c = 1e-300
      d = 1 / d
      h *= d * c
      aa = -(a + m) * (a + b + m) * x / ((a + 2 * m) * (a + 2 * m + 1))
      d = 1 + aa * d; if (Math.abs(d) < 1e-300) d = 1e-300
      c = 1 + aa / c; if (Math.abs(c) < 1e-300) c = 1e-300
      d = 1 / d
      const del = d * c
      h *= del
      if (Math.abs(del - 1) < 1e-14) break
    }
    return h
  }
  return x < (a + 1) / (a + b + 2) ? front * cf(x, a, b) / a : 1 - front * cf(1 - x, b, a) / b
}
