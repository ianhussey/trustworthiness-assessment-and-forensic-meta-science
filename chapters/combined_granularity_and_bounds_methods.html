14  Combined granularity and bounds methods ✎ Draft

Chapter 12 and Chapter 13 describe two families of checks on reported means and SDs. Granularity checks ask whether a reported value can be produced by whole-number data at all: GRIM for the mean and GRIMMER for the SD. Bounds checks ask whether a reported value lies within the range that the scale and the other reported values allow: BRIM for the mean and BRIMMER for the SD (Hussey et al., 2026). The two families divide along two axes, the statistic being checked and the kind of constraint used, which gives four tests.

This chapter is about using the two families together. They answer different questions, so a reported mean and SD can pass one family and fail the other, and checking both rules out many more impossible values than checking either one alone. Even together they are necessary rather than sufficient conditions, and a fifth test, BRIMMEST, settles exactly whether any set of whole-number scores has the reported mean and SD.

14.1 Granularity and bounds are different questions

Granularity and bounds are not nested, with one a stricter version of the other. They are orthogonal: each can pass or fail independently of the other (Hussey et al., 2026). GRIMMER asks whether the reported SD lies on the lattice of values that whole-number data can produce: the sum of the squared scores must be a whole number, with the same parity, odd or even, as the sum of the scores. It does not ask how large or small that SD is relative to the scale. BRIMMER asks only about magnitude: whether the SD lies between the smallest and largest values that the scale, the sample size, and the mean allow. It does not ask whether the SD lies on the lattice.

Three examples, all for five people answering a single item on a 1–5 scale, with means and SDs reported to two decimal places, show the possibilities:

  • A mean of 3.00 and an SD of 2.12 passes GRIM and GRIMMER, but fails BRIMMER. Five whole numbers with a mean of 3 can have a sum of squares that gives an SD of 2.12, so GRIMMER is satisfied. But no five scores between 1 and 5 with a mean of 3 can have an SD above 2.00, which is reached by two scores of 1, one of 3, and two of 5. GRIMMER does not know the scale’s limits, so it cannot see this.
  • A mean of 3.00 and an SD of 1.50 passes BRIMMER, but fails GRIMMER. An SD of 1.50 is comfortably within the bounds of 0 to 2.00, but the sum of squares it implies is even, whereas the sum of five scores with a mean of 3 is odd, so no whole-number data can produce it.
  • A mean of 3.00 and an SD of 1.73 passes GRIM, GRIMMER, and BRIMMER, but is still impossible. The squared deviations from the mean would have to add up to 12, and no five whole numbers between 1 and 5 with a mean of 3 have deviations whose squares add up to 12. All of the tests are necessary conditions, and none of them is sufficient.

The last example is why Hussey et al. (2026) add an exact test, BRIMMEST. For whole-number data, it works out every combination of mean and SD, after rounding, that some sample of whole-number scores on the scale can produce, and checks whether the reported pair is one of them. Unlike the other tests, passing BRIMMEST proves that a report is possible, rather than only failing to rule it out. It gives the same answer as the CLOSURE algorithm, which reconstructs every possible data set, but without reconstructing them.

function cgFrac(x) {
  const f = x - Math.floor(x + 1e-9)
  return f < 1e-9 ? 0 : f
}

function cgCeiling(m, n, l, u) {
  // the largest sample SD with this mean: as many scores as possible at the two ends, and at most one in between
  const R = u - l, S = n * (m - l)
  const nu = Math.min(Math.floor(S / R + 1e-9), n - 1)
  const xr = l + (S - nu * R), nl = n - nu - 1
  return Math.sqrt(Math.max(0, (nl * (l - m) ** 2 + (xr - m) ** 2 + nu * (u - m) ** 2) / (n - 1)))
}

function cgIntegerFloor(m, n) {
  // the smallest sample SD of whole-number scores with this mean, which must be a multiple of 1 / n
  const d = cgFrac(m)
  return Math.sqrt(Math.max(0, n * d * (1 - d) / (n - 1)))
}

function cgQuasiFloor(m, n) {
  // the floor at every mean, drawn as a line: it equals the whole-number floor at the means whole-number data can produce
  const d = cgFrac(m), g = cgFrac(n * m)
  return Math.sqrt(Math.max(0, (n * d * (1 - d) - g * (1 - g)) / (n - 1)))
}

function cgUniform(m, n, l, u) {
  // the uniform-spread bound: the Bhatia-Davis bound divided by the square root of 3
  return Math.sqrt(n / (n - 1) * Math.max(0, (u - m) * (m - l)) / 3)
}

function cgParityMax(l, u, n) {
  return (u - l) / 2 * Math.sqrt(n / (n - 1) * (2 * n * n - 1 + (-1) ** n) / (2 * n * n))
}

function cgAnalyse(l, u, n) {
  const round12 = x => Math.round(x * 1e12) / 1e12
  // every sample of n whole-number scores, as its mean and SD rounded to two decimals, with one example sample for each
  const attainable = new Map()
  const keyHalves = v => [...new Set([Math.floor(v * 100 + 0.5 + 1e-9), Math.ceil(v * 100 - 0.5 - 1e-9)])]
  const scores = []
  const walk = (from, left, sum, sq) => {
    if (left === 0) {
      const mean = sum / n, sd = Math.sqrt(Math.max(0, (sq - sum * sum / n) / (n - 1)))
      for (const mi of keyHalves(mean)) for (const si of keyHalves(sd)) {
        const key = `${mi}|${si}`
        if (!attainable.has(key)) attainable.set(key, scores.slice())
      }
      return
    }
    for (let v = from; v <= u; v++) { scores.push(v); walk(v, left - 1, sum + v, sq + v * v); scores.pop() }
  }
  walk(l, n, 0, 0)

  // the counts are for the reportable pairs: means within the scale and SDs up to the largest any sample can have. the
  // plot also shows the pairs beyond these, out to half a scale point past each end and 10% above that largest SD, where
  // GRIM and GRIMMER, which know nothing of the scale, still accept many reports
  const sdTop = Math.ceil(cgParityMax(l, u, n) * 100 - 1e-9)
  const sdTopPlot = Math.floor(1.1 * cgParityMax(l, u, n) * 100 + 1e-9)
  const miLo = Math.round(l * 100), miHi = Math.round(u * 100)
  const counts = {all: 0, boundsOnly: 0, grim: 0, grimmer: 0, all3: 0, attainable: 0, attainableUniform: 0, grimmerFailBounds: 0}
  const points = []
  const R = u - l
  const perMean = new Map()
  for (let mi = Math.round((l - 0.5) * 100); mi <= Math.round((u + 0.5) * 100); mi++) {
    const inScale = mi >= miLo && mi <= miHi
    const lo = Math.ceil((mi - 0.5) * n / 100 - 1e-9), hi = Math.floor((mi + 0.5) * n / 100 + 1e-9)
    const sums = d3.range(lo, hi + 1)
    // the bounds for continuous data: the largest ceiling over the mean's rounding interval, which is reached at an end
    // of the interval or at a mean where the number of scores at the top of the scale changes
    const mLo = Math.max(l, (mi - 0.5) / 100), mHi = Math.min(u, (mi + 0.5) / 100)
    const kinks = d3.range(Math.ceil((mLo - l) * n / R - 1e-9), Math.floor((mHi - l) * n / R + 1e-9) + 1).map(j => l + j * R / n)
    // a mean outside the scale fails BRIM, so no SD is within the bounds there
    const cmax = inScale ? d3.max([mLo, mHi, ...kinks], m => cgCeiling(m, n, l, u)) : -Infinity
    // the largest uniform-spread bound over the mean's rounding interval. the bound peaks in the middle of the scale, so
    // it is reached at the point of the interval closest to the middle
    const umax = inScale ? cgUniform(Math.min(mHi, Math.max(mLo, (l + u) / 2)), n, l, u) : -Infinity
    perMean.set(mi, {sums, cmax, inScale})
    for (let si = 0; si <= sdTopPlot; si++) {
      const counted = inScale && si <= sdTop
      if (counted) counts.all++
      const sl = Math.max(0, (si - 0.5) / 100), su = (si + 0.5) / 100
      if (counted && sl <= cmax + 1e-9) counts.boundsOnly++
      if (sums.length === 0) continue
      if (counted) counts.grim++
      // GRIMMER, as in scrutiny: some whole-number sum of squares, with the same parity as the sum, gives an SD that
      // rounds to the reported one
      const grimmer = sums.some(s => {
        const x = s / n
        const ql = round12((n - 1) * sl * sl + n * x * x), qu = round12((n - 1) * su * su + n * x * x)
        for (let q = Math.ceil(ql); q <= Math.floor(qu); q++) if (((q % 2) + 2) % 2 === ((s % 2) + 2) % 2) return true
        return false
      })
      // BRIM and BRIMMER for whole-number data: the reported SD's rounding interval meets the bounds at some mean that
      // whole-number data can produce
      const inBounds = sums.filter(s => s >= n * l && s <= n * u).some(s => {
        const x = s / n
        return su >= cgIntegerFloor(x, n) - 1e-9 && sl <= cgCeiling(x, n, l, u) + 1e-9
      })
      const example = attainable.get(`${mi}|${si}`)
      let category
      if (!grimmer) category = "grimmer"
      else {
        if (counted) counts.grimmer++
        if (!inBounds) { category = "bounds"; if (counted) counts.grimmerFailBounds++ }
        else { if (counted) counts.all3++; category = example ? "attainable" : "unattainable" }
      }
      if (example && counted) counts.attainable++
      // allowing for rounding, the reported SD could be at or below the uniform-spread bound
      if (example && counted && sl <= umax + 1e-9) counts.attainableUniform++
      points.push({mean: mi / 100, sd: si / 100, grim: true, inScale, category, grimmer, inBounds, example})
    }
  }
  const byKey = new Map(points.map(d => [`${Math.round(d.mean * 100)}|${Math.round(d.sd * 100)}`, d]))
  return {l, u, n, points, counts, perMean, byKey, sdTop, sdTopPlot}
}

function cgLookup(result, mi, si) {
  // the checks for any reported pair on the grid. pairs whose mean passes GRIM were worked out above. for the others,
  // GRIMMER and BRIMMEST fail too, and the bounds are those for continuous data, since no whole-number data have
  // that mean
  const hit = result.byKey.get(`${mi}|${si}`)
  if (hit) return hit
  const {cmax, inScale} = result.perMean.get(mi)
  const sl = Math.max(0, (si - 0.5) / 100)
  return {mean: mi / 100, sd: si / 100, grim: false, inScale, grimmer: false, inBounds: sl <= cmax + 1e-9, example: undefined}
}

function cgDescribe(d) {
  const tick = ok => ok ? "passes" : "fails"
  const lines = [`Mean ${d.mean.toFixed(2)}, SD ${d.sd.toFixed(2)}`, `GRIM: ${tick(d.grim)}`]
  if (!d.inScale) {
    lines.push(`GRIMMER: ${d.grim ? tick(d.grimmer) : "fails, because the mean fails GRIM"}`)
    lines.push("BRIM: fails, because the mean is outside the scale")
    lines.push("BRIMMER: fails")
    lines.push("BRIMMEST: fails")
    if (d.grim && d.grimmer) lines.push("Possible granularity, impossible magnitude")
    return lines.join("\n")
  }
  if (!d.grim) {
    lines.push("GRIMMER: fails, because the mean fails GRIM")
    lines.push(`BRIMMER: ${d.inBounds ? "within" : "outside"} the bounds for continuous data`)
    lines.push("BRIMMEST: fails")
    lines.push("No whole-number data have a mean that rounds to this value")
    return lines.join("\n")
  }
  lines.push(`GRIMMER: ${tick(d.grimmer)}`, `BRIMMER: ${tick(d.inBounds)}`, `BRIMMEST: ${tick(!!d.example)}`)
  if (d.example) lines.push(`For example: ${d.example.join(", ")}`)
  else if (d.grimmer && !d.inBounds) lines.push("Possible granularity, impossible magnitude")
  else if (!d.grimmer && d.inBounds) lines.push("Possible magnitude, impossible granularity")
  else if (d.grimmer && d.inBounds) lines.push("Passes every necessary check, but no sample produces it")
  return lines.join("\n")
}

GRIM alone rules out all but 5% of them, because five people can only produce means that are multiples of 0.2. GRIMMER rules out most of the rest, leaving 210. But 89 of those 210, 42%, are still impossible, because their SDs lie outside the bounds. These are the orange points, and all of them lie above the ceiling: GRIMMER, which knows nothing about the limits of the scale, admits SDs that are larger than any five scores between 1 and 5 can produce. The bounds alone, without granularity, rule out only about a third of the grid. Combining the two families leaves 121 pairs, of which 102 are attainable. Of those 102, only 48 have an SD at or below the uniform-spread bound, allowing for rounding. The other 54 are possible, but only if the scores pile up at the ends of the scale.

With five people, there are no orange points below the floor. This is not because GRIMMER checks the floor, but because with so few people its lattice is sparse at small SDs: the sum of squares must be a whole number of the right parity, and the smallest such sum of squares above zero happens to give exactly the floor. With five people and a mean of 2.20, for example, the smallest SD that GRIMMER accepts is 0.45, which is the floor. With larger samples the lattice is denser, and GRIMMER accepts SDs below the floor. Set the sample size to 8: a mean of 1.50 with an SD of 0.00 now passes GRIMMER, because the sum of squares it implies, 18, is a whole number with the same parity as the sum of the scores, 12. But it is impossible, because an SD of zero means that everyone had the same score, and eight people with the same whole-number score cannot have a mean of 1.50. Only the floor rules it out.

These percentages are illustrative, not general. They depend on the scale, the sample size, and the reporting precision, and they shift as any of these change. With larger samples, more means pass GRIM, and once the number of people times the number of items reaches 100, every two-decimal mean does, so the bounds carry more of the burden (Hussey et al., 2026). What generalises is the pattern: each check rules out reports that the others let through, so they are most informative together.

14.3 Checking reported values

The app below runs all of these checks on reported values, using the {strait} R package (Hussey, 2026), inside your browser, using webR, as in the other apps in this book. It combines the bounds with granularity, and allows for the rounding of the reported values. With integer responses, it runs GRIM, which checks whether the mean could have come from whole-number data (Section 12.2), and GRIMMER, which does the same for the SD (Section 12.3), alongside BRIMMER, which checks the SD against the bounds, and BRIM, which checks that the mean lies within the scale. A report is consistent only if it passes every check. The Certify (BRIMMEST) button goes one step further, and settles exactly whether any set of whole-number scores has the reported mean and SD. Enter the scale’s minimum and maximum, the sample size, and the reported mean and SD. Enter the mean and SD exactly as reported, including trailing zeros, because the number of decimal places sets how much rounding is allowed for. Choose whether the responses are whole numbers: integer means that every response is a whole number, and quasi-integer, the default, relaxes this by one response, which gives a floor that is defined at every mean and never rules out anything integer data could produce. For a score made up of several items, choose whether it is a sum or a mean of the items. For a sum score, the scale limits are those of the sum; for a mean score, they are those of a single item. Optionally, add a reported Cronbach’s α, or the observed minimum and maximum. strait has no joint bounds for α and observed extremes, so when both are given the app combines the two sets of bounds, taking the higher floor and the lower ceiling. This is valid, but may not be as sharp as possible. The plot shows the possible combinations of mean and SD as a shaded band, with the reported values as a point. The first check takes several seconds, because R and strait have to be downloaded.

// it can be, and otherwise on a grid of sd_bounds() calls. with both a reported alpha and observed extremes, for which

brHelpersR = `
br_args <- function(p) list(l = p$l, u = p$u, n = p$n, Z = p$Z, scoring = p$scoring, n_items = p$k)
br_grid <- function(p, a, b, alpha, means) {
  do.call(rbind, lapply(means, function(mu) {
    d <- tryCatch(do.call(sd_bounds, c(br_args(p), list(a = a, b = b, alpha = alpha, mean = mu))), error = function(e) NULL)
    if (is.null(d)) return(data.frame(mean = mu, min_sd = NA_real_, max_sd = NA_real_, feasible = FALSE))
    data.frame(mean = mu, min_sd = d$min_sd, max_sd = d$max_sd, feasible = isTRUE(d$feasible))
  }))
}
br_curve <- function(p, a, b, alpha) {
  m <- if (p$scoring == "meanscored") p$k else 1
  thinned <- (floor(p$u * p$n * m) - ceiling(p$l * p$n * m) + 1) > 600
  if (is.null(a) && !thinned) {
    out <- do.call(sd_bounds_curve, c(br_args(p), list(alpha = alpha)))[, c("mean", "min_sd", "max_sd", "feasible")]
  } else {
    means <- seq(p$l, p$u, length.out = 700)
    out <- br_grid(p, a, b, if (is.null(a)) alpha else NULL, means)
    if (!is.null(a) && !is.null(alpha)) {
      al <- br_grid(p, NULL, NULL, alpha, means)
      out$min_sd <- pmax(out$min_sd, al$min_sd)
      out$max_sd <- pmin(out$max_sd, al$max_sd)
      out$feasible <- out$feasible & al$feasible & out$min_sd <= out$max_sd + 1e-9
    }
  }
  out$feasible <- out$feasible & is.finite(out$min_sd) & is.finite(out$max_sd)
  out$min_sd[!out$feasible] <- NA
  out$max_sd[!out$feasible] <- NA
  attr(out, "thinned") <- thinned
  out
}
br_check <- function(p, a, b, alpha) {
  args <- c(br_args(p), list(mean = p$mean, mean_digits = p$md, sd = p$sd, sd_digits = p$sdd, rounding = p$rounding))

    r <- do.call(brimmer, c(args, list(a = a, b = b, alpha = alpha)))
    s <- do.call(sd_bounds, c(args, list(a = a, b = b, alpha = alpha)))
    r$min_rule <- s$min_rule
    r$max_rule <- s$max_rule
    r
  }

  r2 <- one(a, b, NULL)

  max_sd <- min(r1$max_sd, r2$max_sd)
  inb <- isTRUE(iv$hi >= min_sd - 1e-9 && iv$lo <= max_sd + 1e-9)
  failed <- setdiff(unique(c(strsplit(r1$failed_tests, ",")[[1]], strsplit(r2$failed_tests, ",")[[1]])), c("", "bounds"))

  out <- r2
  out$min_sd <- min_sd
  out$max_sd <- max_sd
  out$sd_in_bounds <- inb

  out$consistent <- length(failed) == 0
  out$min_rule <- if (r1$min_sd >= r2$min_sd) paste(r1$min_rule, "(alpha)") else paste(r2$min_rule, "(observed extremes)")
  out$max_rule <- if (r1$max_sd <= r2$max_sd) paste(r1$max_rule, "(alpha)") else paste(r2$max_rule, "(observed extremes)")

}

  reference <- if (is.null(a)) NULL else br_curve(p, NULL, NULL, alpha)

  # plain data frames, without extra attributes, which webR cannot convert
  plain <- function(df) if (is.null(df)) NULL else data.frame(lapply(as.list(df), as.vector), stringsAsFactors = FALSE)
  list(report = plain(report), curve = plain(curve), reference = plain(reference), thinned = isTRUE(attr(curve, "thinned")), band = band)
}

async function brRun(p) {
  const {webR, rVersion, straitVersion} = await brR.get()
  const shelter = await new webR.Shelter()
  try {
    // the values are passed to R as named values, never pasted into the code
    const env = {l: p.l, u: p.u, n: p.n, Z: p.Z, scoring: p.scoring, k: p.k, mean: p.mean, md: p.md, sd: p.sd, sdd: p.sdd, rounding: p.rounding,
      useAB: p.useAB, a: p.useAB ? p.a : 0, b: p.useAB ? p.b : 0, useAlpha: p.useAlpha, alpha: p.useAlpha ? p.alpha : 0}
    const res = await (await shelter.evalR(`
      p <- list(l = l, u = u, n = n, Z = Z, scoring = scoring, k = k, mean = mean, md = md, sd = sd, sdd = sdd, rounding = rounding)
      strait_env$br_run(p, if (useAB) a else NULL, if (useAB) b else NULL, if (useAlpha) alpha else NULL)
    `, {env})).toJs()
    // the result is a list of data frames, each a list of columns, which are turned into arrays of rows here
    const part = name => res.values[res.names.indexOf(name)]
    const frame = df => df?.names ? d3.range(df.values[0]?.values.length ?? 0).map(i => Object.fromEntries(df.names.map((c, j) => [c, df.values[j].values[i]]))) : null
    return {report: frame(part("report"))[0], curve: frame(part("curve")), reference: p.useAB ? frame(part("reference")) : null,
      thinned: part("thinned").values[0], band: part("band").values, rVersion, straitVersion}
  } finally {
    shelter.purge()
  }
}

async function brCertify(p) {
  if (p.useAB) throw new Error("The exact certificate does not take observed extremes. Untick that option to use it.")
  if (![p.l, p.u].every(Number.isInteger)) throw new Error("The exact certificate needs whole-number scale limits, because it enumerates whole-number data.")
  const {webR, rVersion, straitVersion} = await brR.get()
  const shelter = await new webR.Shelter()
  try {
    // brimmest() takes the forward rounding rules; halves either way admits both half rules
    const rules = {up_or_down: ["half_up", "half_down"], up: ["half_up"], down: ["half_down"], even: ["native"]}[p.rounding] ?? [p.rounding]
    const res = await shelter.evalR(`
      r <- strait_env$brimmest(l = l, u = u, n = n, mean = mean, sd = sd, mean_digits = md, sd_digits = sdd,
                               rounding = rules, scoring = scoring, n_items = k)
      data.frame(possible = isTRUE(r$possible[1]), rules = as.character(r$rules[1]))
    `, {env: {l: p.l, u: p.u, n: p.n, mean: p.mean, sd: p.sd, md: p.md, sdd: p.sdd, rules, scoring: p.scoring, k: p.k}})
    const js = await res.toJs()
    const out = Object.fromEntries(js.names.map((c, j) => [c, js.values[j].values[0]]))
    return {...out, p, rVersion, straitVersion}
  } finally {
    shelter.purge()
  }
}

function brChecked(v) {
  // reads and checks the inputs. the decimal places of the reported mean and SD are read from the values as typed
  const number = s => /^[-+]?(\d+\.?\d*|\.\d+)$/.test(s.replace(/[−–]/g, "-")) ? Number(s.replace(/[−–]/g, "-")) : NaN
  const decimals = s => s.match(/\.(\d*)$/)?.[1].length ?? 0
  const p = {Z: v.Z, scoring: v.scoring, rounding: v.rounding, useAlpha: v.useAlpha && v.scoring !== "singleitem", useAB: v.useAB, problems: []}
  for (const key of ["l", "u", "n", "mean", "sd"]) p[key] = number(v[key])
  p.k = v.scoring === "singleitem" ? 1 : number(v.k)
  p.md = decimals(v.mean); p.sdd = decimals(v.sd)
  p.meanText = v.mean; p.sdText = v.sd
  if (![p.l, p.u, p.n, p.mean, p.sd].every(Number.isFinite)) p.problems.push("Enter the scale minimum and maximum, the sample size, and the reported mean and SD as numbers.")
  else {
    if (!(p.u > p.l)) p.problems.push("The scale maximum must be greater than the scale minimum.")
    if (!Number.isInteger(p.n) || p.n < 2) p.problems.push("The sample size must be a whole number of at least 2.")
    if (p.sd < 0) p.problems.push("An SD cannot be negative.")
  }
  if (v.scoring !== "singleitem" && (!Number.isInteger(p.k) || p.k < 2)) p.problems.push("A sum or mean of items needs at least two items.")
  if (p.useAlpha) {
    p.alpha = number(v.alpha)
    if (!(p.alpha > -1 && p.alpha < 1)) p.problems.push("Cronbach's α must be a number between −1 and 1.")
  }
  if (p.useAB) {
    p.a = number(v.a); p.b = number(v.b)
    if (![p.a, p.b].every(Number.isFinite)) p.problems.push("Enter the observed minimum and maximum as numbers.")
    else if (!(p.b > p.a)) p.problems.push("The observed maximum must be greater than the observed minimum.")
    else if (p.a < p.l || p.b > p.u) p.problems.push("The observed minimum and maximum must lie within the scale limits.")
  }
  if (p.Z !== "continuous" && [p.l, p.u, ...(p.useAB ? [p.a, p.b] : [])].some(x => Number.isFinite(x) && !Number.isInteger(x))) {
    p.problems.push("Integer and quasi-integer responses need whole-number limits. For a mean of items, these are the limits of a single item.")
  }
  return p
}

function brVerdict(r, p) {
  // the verdict, headline and explanation, following the strait web app. a failure proves that the reported values
  // are impossible; a pass only means that the checks could not rule them out
  const failed = r.failed_tests ? r.failed_tests.split(",").filter(Boolean) : []
  const gloss = {
    in_scale_range: "the reported mean cannot be reached on this scale at this sample size, at any SD",
    bounds: `the reported SD lies outside the bounds that the reported mean${p.useAlpha ? ", the reported α" : ""}${p.useAB ? ", the observed minimum and maximum" : ""} and the sample size imply, so no data on this scale have all of them`,
    grim: "GRIM: no sample of whole-number scores of this size has a mean that rounds to the reported value",
    grimmer: "GRIMMER: the reported SD cannot be produced by whole-number data at this mean",
    feasibility: "the constraints admit no sample at all, for a reason none of the other checks accounts for"
  }
  if (failed.length === 0) return ["ok", "Consistent", "The reported values pass every check that was applied. These checks are necessary but not sufficient: consistent means that the report could not be ruled out, not that data producing it are known to exist. For whole-number data, the exact certificate settles that."]
  const onlyGrimmer = failed.length === 1 && failed[0] === "grimmer"
  const text = failed.map(t => gloss[t] ?? t).join("; ")
  return [onlyGrimmer ? "warn" : "bad", onlyGrimmer ? "Flagged by GRIMMER only" : "Inconsistent",
    text.charAt(0).toUpperCase() + text.slice(1) + ". " + (onlyGrimmer ? "The bounds pass, and scrutiny's GRIMMER has documented false flags, so check this before acting on it." : "The reported values cannot all be correct as printed.")]
}

// the rounding rules, described as in the GRIM and GRIMMER apps of the granularity chapter
brRoundingPhrases = ({up_or_down: "halves rounded up or down", up: "halves rounded up", down: "halves rounded down", even: "halves rounded to even", trunc: "values truncated", anti_trunc: "values rounded away from zero", ceiling: "values rounded up", floor: "values rounded down"})

function brParityMax(l, u, n) {
  // the largest SD any sample of this size can have on this scale, whatever its mean (Popoviciu, with the odd-n case)
  return (u - l) / 2 * Math.sqrt(n / (n - 1) * (2 * n * n - 1 + (-1) ** n) / (2 * n * n))
}

function brResults(res, p, units) {
  const {report: r, curve, reference, thinned, band} = res
  const [kind, headline, gloss] = brVerdict(r, p)
  const fmt = (x, d = 3) => Number.isFinite(x) ? x.toFixed(d) : "—"
  const scaleFree = units === "scalefree"
  // in scale-free units, the mean is the percent of the way along the scale, and the SD is a percent of the largest SD
  // any sample of this size on this scale can have
  const pm = brParityMax(p.l, p.u, p.n)
  const tx = m => scaleFree ? 100 * (m - p.l) / (p.u - p.l) : m
  const ty = s => s == null ? NaN : scaleFree ? 100 * s / pm : s
  const pass = x => x === true ? "pass" : x === false ? "fail" : null
  const cells = [
    ["Reported mean", p.meanText], ["Reported SD", p.sdText],
    ["Smallest possible SD", fmt(r.min_sd)], ["Largest possible SD", fmt(r.max_sd)],
    ["Binding floor", (r.min_rule ?? "—").replace(/ \(envelope over rounding interval\)/, "")],
    ["Binding ceiling", (r.max_rule ?? "—").replace(/ \(envelope over rounding interval\)/, "")],
    ...(p.useAB ? [["Possible means", `${fmt(band[0], 2)} to ${fmt(band[1], 2)}`]] : []),
    ...(pass(r.grim) ? [["GRIM", pass(r.grim)]] : []),
    ...(pass(r.grimmer) ? [["GRIMMER", pass(r.grimmer)]] : [])
  ]
  const feasible = curve.filter(d => d.feasible)
  const line = rows => rows.map(d => ({x: tx(d.mean), lo: ty(d.min_sd), hi: ty(d.max_sd)}))
  const data = line(curve), ref = reference ? line(reference) : null
  const yMax = 1.08 * d3.max([...data, ...(ref ?? [])].map(d => d.hi).filter(Number.isFinite).concat([ty(p.sd)]))
  const colour = kind === "ok" ? "#3b9c6e" : kind === "warn" ? "#d9a02b" : "#c0392b"
  const plot = Plot.plot({
    width, height: 380, marginLeft: 55, marginRight: 20, marginTop: 15, marginBottom: 45,
    x: {label: scaleFree ? "Mean (percent of the scale)" : "Mean", labelAnchor: "center", labelOffset: 36, domain: [tx(p.l), tx(p.u)]},
    y: {label: scaleFree ? "SD (percent of the largest possible)" : "SD", labelAnchor: "center", labelOffset: 45, domain: [0, yMax], grid: true},
    style: {fontSize: "13px"},
    marks: [
      // the possible combinations of mean and SD
      Plot.areaY(data, {x: "x", y1: "lo", y2: "hi", fill: "#2780e3", fillOpacity: 0.18}),
      ref ? Plot.line(ref, {x: "x", y: "hi", stroke: "currentColor", strokeOpacity: 0.35, strokeDasharray: "4,3"}) : null,
      ref ? Plot.line(ref, {x: "x", y: "lo", stroke: "currentColor", strokeOpacity: 0.35, strokeDasharray: "4,3"}) : null,
      Plot.line(data, {x: "x", y: "hi", stroke: "#2780e3", strokeWidth: 1.5}),
      Plot.line(data, {x: "x", y: "lo", stroke: "#2780e3", strokeWidth: 1.5}),
      p.useAB ? Plot.ruleX(band.map(tx), {stroke: "currentColor", strokeOpacity: 0.5, strokeDasharray: "2,3"}) : null,
      Plot.ruleY([0]),
      Plot.dot([{}], {x: tx(p.mean), y: ty(p.sd), r: 6, fill: colour, stroke: "white", strokeWidth: 1.5})
    ]
  })
  const notes = [
    `The shaded band shows the combinations of mean and SD that the constraints allow, and the point shows the reported mean and SD, in green if they are consistent and in red if not.${scaleFree ? " In scale-free units, the mean is the percent of the way from the scale minimum to the maximum, and the SD is a percent of the largest SD that any sample of this size on this scale can have, whatever its mean." : ""}`,
    ref ? "The dashed lines show the bounds from the scale limits alone, and the dotted vertical lines the range of means that are possible when the observed minimum and maximum are both attained." : null,
    p.useAB && p.useAlpha ? "With both a reported α and observed extremes, the bounds are the higher of the two floors and the lower of the two ceilings. These are valid, but may not be as sharp as possible." : null,
    p.Z === "integer" ? "With strictly integer responses, the band only exists at the means that a whole-number sum can produce, so it is drawn with gaps. Quasi-integer responses relax this by one response." : null,
    thinned ? "This design has more possible means than the plot can show, so the band is drawn on a grid of means. Only the drawing is approximate: the verdict comes from the reported values themselves." : null
  ].filter(Boolean)
  const verdict = html`<div class="sb-feedback sb-feedback-${kind}"><strong>${headline}.</strong> ${gloss}</div>`
  return html`<div>
    ${verdict}
    <div class="br-stats">${cells.map(([k, v]) => html`<div class="br-stat"><div class="k">${k}</div><div class="v">${v}</div></div>`)}</div>
    ${plot}
    ${notes.map(t => html`<div class="sc-status br-note">${t}</div>`)}
    <div class="sc-status">Checked by <code>brimmer()</code> and <code>sd_bounds()</code> from strait ${res.straitVersion} (commit <a href="https://github.com/ianhussey/strait/tree/${straitCommit}">${straitCommit.slice(0, 7)}</a>), ${res.rVersion}, running in webR ${brWebrVersion}. The mean was taken as rounded to ${p.md} decimal place${p.md === 1 ? "" : "s"} and the SD to ${p.sdd}, with ${brRoundingPhrases[p.rounding]}.</div>
  </div>`
}
